# NRIproperty Registration Website

Responsive landing page developed from the supplied NRI Services Landing Page reference.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Replace before launch
- WhatsApp number in `index.html`
- Phone number in `index.html`
- Email address in `index.html`
- Privacy / Terms / Disclaimer page URLs
- Brand/logo details if final assets differ
- Legal copy after client approval
